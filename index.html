ROADSTER AIR RUN · 一场虚构的公路冒险
DRIVER’S MANUAL

上路，只需一个按钮。

01
长按喷气

按住空格、↑、W 或屏幕上的喷气按钮，Roadster 会持续上升；松开后自然下落。车速会随行驶时间缓慢提升。

02
管理高压空气

只有按住喷气时每秒消耗 25.5% 空气。松开后，空中滑行不耗气也不回气；落地每秒恢复 6%。短促喷气配合滑行更省气。

03
右侧障碍，左侧突袭

轿车、SUV、厢式货车、箱式卡车和半挂卡车会交替出现，偶尔组成紧挨的车队。高大货车需要提前起飞。行驶越久，左侧突袭越频繁；每次保留 2 秒预警。左侧红色感叹号出现后，尊界 V800 会高速冲入，撞上前方车辆并起火。任何车辆碰撞都会结束本局。

 ABOUT THE RUN

气动逃逸 · Roadster Air Run

一款关于反应、节奏和空气管理的公路街机游戏。Roadster 和尊界 V800 使用公开侧视图片，V800 图片已去除背景；障碍车辆、城市、粒子和火焰为程序绘制。

车型名称用于虚构游戏情节；游戏中的速度、碰撞和起火效果均为夸张演出。
